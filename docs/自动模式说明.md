## Skill 架构下的目标（2026-10-19，未实施）

见 [目标架构](Skill双流程架构设计.md)。自动模式未来绑定 project、流程、Agent 执行方式、skill_id@version/内容摘要，以及现有可见集/脚本/Provider/预算身份。MCP 外部 Agent 与 API 内置 Agent 统一走 Go 的权限、工具和审计；人类确认不能由 Agent 或 system:auto-review 代做。

Skill 更新、项目/流程/执行方式切换和权限撤销使旧授权失效；采用既有决策卡和精确修订确认。未定稿试跑仅供草稿预览，不能正式交付。外部 Agent 推理费用未知时显示未知，VAC 仅强制自身工具预算；内置推理受轮次/token/费用限额。原 auto_driver 与旧流程保持兼容，DEV05 的脚本消费缺口纳入 S2/S6，仍未完成。以下原覆盖层说明只描述当前实现。


更新：2026-10-18；依据 agent/develop 中 auto*.go、autoreview 与 AutoRunPanel/autoRun.ts。旧带日期设计仅供溯源；本轮验证见 [整合记录](开发分支合并-2026-10-18.md)。

自动模式是原工作流的覆盖层。启动绑定素材版本、预设 ID/版本、brief 摘要、预算、notice 摘要与当前可见集；需明确授权。素材、预设或告知摘要变化立即清除勾选，发送前再核对身份。放宽阈值另行确认，外部提供方遵守固定预设版本的外发许可。

资源页区分入库与 Agent 可见。尚未确认可见集时不能进入脚本或启动生成；可见集变化会使脚本/交付失效，并暂停相关自动流程。脚本内容改变或重生成同样暂停，人工只能确认已定稿的精确稿件版本。

| 状态或动作 | 实际行为 |
|---|---|
| 高档 | 自动路径完成、释放 hold，投影当前交付；不写人工验收 |
| 中档 | 等用户决定，可用时导出、修改或放弃 |
| 低档可改进 | 在次数、动作、时间、TTS 预算内重剪；耗尽后等决定或停止 |
| confirm_visible_set | 仅人工确认当前可见集后恢复 |
| confirm_script | 仅人工携带 script_id/script_version 确认精确定稿修订后恢复 |
| discard | 二次确认后停止自动模式，已有文件保留 |
| revoke | 撤销本次自动授权，可另行选择撤销预设外发许可 |
| 人工验收 | 与覆盖层关闭同事务；成功 human_completed，失败 human_rejected；混合记录保留拒绝结果 |

修改带 expected_auto_version，决定带幂等键。并发对账在锁内重新读取 run 与 auto_version；过期快照不得覆盖新状态。新会话默认分步，不读取旧模式 localStorage；活跃自动任务继续显示。决策卡同时区分可导出能力与交付 hold，不显示不可达的“已确认”。

自评权重：识别 0.35、TTS 0.20、音画对齐 0.30、节奏 0.15；默认高档 0.85、中档 0.60，另受分项门槛和不可改进原因限制。这是机器路由规则，尚未代表真实作品质量已校准。

CR01 拒绝提供方重定向、CR02 版本/告知授权失效修复已整合。CR03 时间线纯键盘焦点审批对象问题仍待处理；本轮未运行浏览器冒烟。本次已补 TTS 专页回写与直接脚本配音接线，未验证；auto_driver 仍只检查脚本范围，完整脚本到旧自动链尚未完成；人工全流程、真实模型/Premiere 与发行独立待验。
