# agent/flow-optimize 阶段目标与验收点

仓库 KiriuKazurei/Video-A-Cut。基线 `agent/main` @ `4bdd5d6`。开发基于 `agent/flow-optimize`，不碰 `main`，每阶段交 Gate，通过后进下一阶段，合进 `agent/main` 需和零批准。

## 总目标
主路径改成脚本工作台，四段：导入 → 选素材（Agent 可见）→ 脚本 → 成片/站内预览/进 PR。
功能入口沿用现有布局和页签，不新增顶层入口，不做蓝图式主界面。
TTS 保留专门分页（音色、语气、频谱台、时间轴按轴调语气）；脚本段只决定是否启用 TTS 与挂接哪些段落，细调不并入脚本工作台。

## Gate 门禁（四条，贯穿所有阶段）
G1. 「Agent 可见素材」与「脚本定稿」两个确认点，自动模式不得静默跳过；自动模式只能在已授权范围内走，缺确认即停在决策卡。
G2. 两条脚本路径各自可独立验收：路径 A 人写脚本；路径 B Agent 先看素材再生成。生成稿可编辑、可否决、可重新生成。
G3. TTS 与字幕关闭不挡成片；开启时能从脚本段跳到 TTS 专页并对上时间线；专页改动（音色/语气/频谱/轴）能回写成片。
G4. 交付物与 `delivery.zip` / 720p 对齐，或明确替换并写入文档与 UI 文案。

## 口径补充（Gate 条件通过后补入，F1 开工前定稿）
C1. G1 口径【和零已定 A，2026-10-17】：启动时的全局授权即对「可见集 + 脚本定稿」的人工授权；授权页必须逐项列出范围并留痕。超范围（可见集变化、生成稿被改/重生成）时自动模式停决策卡，需重新授权或人工确认。新增确认动作一律进人工白名单，`system:auto-review` 与 agent 的 actor 不能代点。
C2. 兼容：已有素材默认「Agent 可见」状态等于现状（入库即可见），进行中的 run 按现状视为已确认，不得被卡死；非自动 run 的 JSON 形状（golden）与 B1–B4 的 API 保持兼容，新增字段只增不改，有改动逐项在交审时列出。
C3. 「过期」：可见集变化后，下游脚本标记过期但不删除；已定稿稿件作废为「待重新定稿」，需人工再确认；已有成片与交付包标记失效，不可继续下载，重新渲染后生成新版本。
C4. 依赖：F1 → F2 → F3 → F4 顺序，F3 依赖 F2，F4 依赖 F3；F0 可与 F1 并行但先交审。

## 阶段
### F0 基线与债务（先做）
- 目标：在 `agent/flow-optimize` 上清 B3/B4 测试债：Node brief 哈希不匹配测试空转、对账 `auto_version` 竞态等存活变异；记录 playwright 首次安装步骤。
- 验收：对应测试能真实失败（变异后红）；`go build/vet/gofmt`、`go test -race`、webui check/build/单测与 smoke 保持现有基线或更好；不新增 FAIL。

### F1 素材段（Agent 可见）
- 目标：在现有素材/资源页内，明确「入库」与「Agent 可见」两层状态，可批量切换，进入脚本前有可见素材确认。
- 验收（G1）：未确认可见素材时，手动与自动模式都不能进入脚本段或开始生成；改动可见集合后下游脚本标记为过期；有 UI 与 API 测试。

### F2 脚本工作台（两条路径）
- 目标：脚本段用现有编辑页布局，提供路径 A（人写、按段挂素材）与路径 B（Agent 先看可见素材再出稿）。稿件按段保存，可编辑、否决、重生成、定稿。
- 验收（G1、G2）：A、B 各自有端到端用例；路径 B 的定稿动作必须是人工的，并有变异测试（去掉人工检查应变红）；B 的生成稿必须经人确认后才算定稿；自动模式遇到未定稿停在决策卡；定稿前后版本可回看。

### F3 TTS 与字幕挂接
- 目标：脚本段内只有「启用 TTS」「启用字幕」与段落挂接开关；开启 TTS 时有跳转入口到 TTS 专页并定位到对应段落和时间位置。
- 验收（G3）：两开关全关时能出成片且时间线正确；开 TTS 后从脚本段跳转到专页，专页改音色/语气/频谱/轴后回到成片能看到更新；回写有测试；文档写明回写到哪个修订，回写后旧预览与交付包必须失效、不能带着旧下载。

### F4 成片、站内预览与交付
- 目标：成片段做站内预览，一键进 PR/交付；说明交付物清单。
- 验收（G4）：交付物与 `delivery.zip` 和 720p 预览一致，或明确替换并更新文档与 UI 文案；真渲染与字体烟测须在有真实字体环境的机器上跑（云电脑没有，不在此空过），文档写明机器与执行人。此处「进 PR」指进 Premiere 的交付，不是 GitHub PR，也不外发。

## 不做
不新增顶层入口；不把 TTS 细调并入脚本工作台；不改 `main`；Premiere A08 仍待 Windows，不挡本轮。
