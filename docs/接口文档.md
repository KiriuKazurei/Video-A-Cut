## 1. 地址、身份与通用传输

桌面从 `runtime_status.api_base_url` 取得实际 `http://127.0.0.1:<端口>`，由 runtimeUrl.apiURL 统一拼接 `/api/`；SSE、媒体和下载使用同一地址。浏览器开发保留相对 URL，不硬编码生产端口。MCP 地址独立读取 `mcp_url`，不能把 `/mcp` 送进只接受 `/api/` 的 URL helper。

| 入口 | 身份/参数 | 边界 |
|---|---|---|
| 可见窗口 HTTP/IPC | 人工身份；无人工 Token/Cookie/解锁 | 鼠标、键盘和窗口自动化相同，不需要手工授权凭证 |
| 工程请求 | 可带 `X-VAC-Project-Session` | 工作副本标识，用于拒绝切换后的旧请求，不是鉴权凭证 |
| 外部 Agent `/mcp` | 自动 MCP 会话、客户端信息、固定 Agent 角色 | 只发现当前工程；owner、工具名单和版本由 Go 校验 |
| 内部 Worker `/mcp` | `Authorization: Bearer ...`、角色/租约、必要时 execution scope | 不因窗口免凭证取消内部任务边界 |

JSON 写入使用 Content-Type application/json。响应有裸对象、裸数组或特定 wrapper，不能给所有成功对象再包一层 data。错误采用 `{ "error": { "code": "...", "message": "..." } }`；400 参数/格式、403 角色/权限、404 不存在或非当前工程、409 版本/状态冲突、410 退休工程流程，其他状态按 handler 的现有映射处理。媒体不是 JSON；Range 成功可为 206，范围错误为 416，缓存及内容头由实际 handler 给出。

写请求需要的 expected_version、expected_draft_version、script_version、plan_version 等不是同一版本号。先读取目标对象，再用对应 CAS；遇冲突重新读，保留用户草稿并明确目标，不携旧内容套新 CAS 强写。幂等键绑定同一语义请求，传输重试复用，明确的新尝试使用新键。超时/连接断开不等于服务端没有执行，先查询当前状态或原请求结果。

本地转录预设：`api_format=faster_whisper`、必填绝对 `model_path`，可选绝对 `python_executable`、`device=cpu|cuda`、`compute_type`、2–3 字母 `language`、`cpu_threads`（0 使用默认 4，1–16 显式值）。CPU 支持 int8/float32，CUDA 另支持 float16/int8_float16；不允许混入 endpoint/model/token_env。云转录仍为 elevenlabs/scribe_v1 + endpoint/token_env，不接受本地字段。预设是不可变版本，凭据不写入 AVP。

`POST /api/processing-profiles/transcription/check` 接收上述本地 Provider，返回 `{ok,code,message,python_executable?,model_fingerprint?,dependency_version?}`；配置无效 400，缺失模型/依赖为 200 + ok=false。30 秒有界，可取消；不要求当前工程或云 Key，不加载模型/识别/下载。实际 media.transcribe 仍受当前运行的媒体、工具、转录许可及时间窗约束。

桌面 `project_dialog` 增加 transcription-model（目录）、transcription-python（exe）模式，同时新增 clipboard_write_text({text})，由调用窗口提供 HWND，成功返回 null，写入失败拒绝 Promise。设置从共享 runtime-status 取 ready 状态 mcp_url；连接配置只含实时回环 URL，支持 mcpServers JSON 与 `[mcp_servers.vac]` TOML，通过 clipboard_write_text 复制并报告失败。

## 2. 工程文件与资源接口

### 2.1 当前会话和文件命令

`GET /api/workspace` 返回 `ProjectSession`：

| 字段 | 类型 | 含义 |
|---|---|---|
| id | string | 当前工作副本会话 ID；工程切换后不能沿用 |
| path / dirty / revision | string / bool / uint64 | 正式文件位置、未保存状态及工作副本修订 |
| active_tasks | integer | 工程活动任务数，用于切换/退出提示 |
| document | AvpDocument 或 null | 当前工程；首页可能为 null |
| recent | `{path,name,opened_at}[]` | 最近工程，默认至多 10 项 |
| recoveries | `{path,name,recovery_path,updated_at}[]` | 本地恢复入口 |

`POST /api/workspace/{action}` 接收 `ProjectCommand`，返回更新后的 Session：

| 参数 | 类型/可选 | 说明 |
|---|---|---|
| path | string | new/open/save-as 的目标 `.avp`；按 action 使用 |
| name | string，可选 | 新工程名称，new 必需 |
| decision | `save` / `discard`，可选 | 当前 dirty 时的显式决定；省略用于先获取冲突并显示提示 |
| stop_tasks | bool | 切换涉及活动任务时必须明确停止并等待排空 |
| expected_session | string，可选 | 请求所依据的工作副本 ID，过期返回冲突 |
| recovery_path | string，可选 | recover 使用受控恢复路径，不能指向任意恢复根外文件 |

action 为 new/open/recover/save/save-as/close/undo/redo。new 要求非空名称、`.avp` 路径及不存在的目标；open/recover 先解析并验证目标，再处理当前 dirty/任务。save 只更新当前正式文件；save-as 建独立工程 ID。undo/redo 作用于资源历史，运行历史有独立接口。取消、无效目标或保存/停止失败不切换工程。

`POST /api/workspace/inspect-project`：`{path}` → 工程 Identity，先验证但不改变当前工作区。`PATCH /api/workspace/state`：`{session,state}` → Session，只保存布局/当前工作区等状态。`GET/PUT /api/workspace/providers`：读取/保存全局 `{external_tts:boolean}`；模型/转录预设能力及外发许可继续使用处理预设接口，不把 credentials 放进 state 或工程。

### 2.2 工程资源

`GET /api/projects/{id}/resources` → `ProjectResource[]`；页面通常从 workspace.document.resources 取同一快照，无需重复请求。`POST` 同一路径以 `{path}` 导入本地文件，返回 Session。这里的本地路径来自窗口原生文件选择，不是给 MCP 的任意磁盘读取工具。

资源字段包括 id/kind/name/source/metadata/notes/in/out/missing，以及可选 removed/changed/referenced/asset_id/script_id。kind 为 video/audio/image/subtitle/document/script；source 为相对路径、原位置、SHA、size 和修改时间。入出点是源资源秒数，必须有限且满足 `0 ≤ in ≤ out`。

`PATCH /api/projects/{id}/resources/{resource}` 接收可选 `{name,notes,in,out,path,removed}`，返回 Session；path 用于重新定位，removed 只移除工程引用，被引用资源保留缺失占位。没有请求字段表示“删除磁盘原件”。

`GET .../{resource}/content` 返回源媒体或文本；`?proxy=1` 读取已生成代理。视频/音频支持常规媒体 Range；文稿、字幕和脚本为 UTF-8 文本，脚本返回正文。`POST .../{resource}/preview` → `{ready:boolean}`，本地创建所需代理。直接 ID 和字节读取同样检查当前工程，不能靠保留旧 URL 访问别的工程。

### 2.3 脚本文件

| 路径 | 请求 | 返回/约束 |
|---|---|---|
| POST `/api/workspace/inspect-script` | `{path}` | AvsDocument，用于展示绑定选择，不导入 |
| POST `/api/projects/{id}/scripts/import-file` | ScriptFileImport | Session；形成工程副本 |
| PATCH `/api/projects/{id}/scripts/{script}/bindings` | ScriptFileImport | Session；解决待关联项 |
| POST `/api/projects/{id}/scripts/{script}/export-file` | `{path}` | `{saved:true}`；显式导出 `.avs` |

`ScriptFileImport = {path,script_only,bindings,files}`：bindings 将原 binding ID 映射到当前 resource ID，files 将 binding ID 映射到本地文件；script_only=true 不带入旧素材，保留 unresolved 及段落关系。未解决绑定允许编辑，但依赖素材的生成/渲染不能继续。

### 2.4 正式文件结构

`.avp` / `.avs` 要求 UTF-8 JSON、正确扩展名；写版本 2，读版本 1/2，打开不改原文件。读入限 128 MiB，拒绝尾随多余内容、重复/无效稳定 ID、未知资源类型和无效时间范围。完整 Go 模型为 [document.go](../control-plane/internal/project/document.go) 与 [timeline.go](../control-plane/internal/project/timeline.go)。

| 文档 | 字段 |
|---|---|
| AvpDocument | format、schema_version、project `{id,name,created_at,updated_at}`、resources、scripts、sequences、settings、workspace、可选 runtime 和 file_references |
| AvsDocument | format、schema_version、id/title/body、segments、bindings、references、tts_enabled/subtitles_enabled/allow_web_research、可选 sources/revisions |
| Binding | id/name/kind、可选 resource_id、unresolved、可选 segment_indexes；kind 为 video/audio |
| runtime | 版本化白名单的工程可编辑表投影，不接受全局表/凭据；由 Go 校验并恢复 |

### 2.5 已退休的工程流程

AVP 工作区启用时，下列旧路径仍可能在兼容注册清单中，但由 workspaceGate 返回 410：PATCH `/api/assets/{id}`、POST `/api/assets/visibility`、POST `/api/recordings`、POST `/api/deliveries/import`、POST `/api/projects`、PUT `/api/projects/{id}`、POST `/api/projects/{id}/media`，以及 visible-set/confirm 旧确认入口。使用新文件/资源接口，不在 410 后自动回退旧流程。

### 2.6 多序列、编辑事务和带类型引用

完整端点见 TL-01～TL-14；音频片段音量谱使用 TL-14 `loudness`（峰值/RMS 分桶、保留原声道取最大峰值、按源哈希+流+版本缓存；显示范围 -60 dBFS 底至 0 dBFS 顶，低于底按静音、高于 0 dBFS 钳为满格），旧 TL-11 `waveform` 仅保留兼容；SDK 为 timelineApi。新建/复制/删除序列使用工程 revision，编辑命令使用序列 revision，二者都携带 session 和幂等键；旧工程会话和旧修订分别冲突，不在失败后自动改键重发。拖入、流展开、链接分割和 Skill 入轨是一条原子历史。人工历史摘要可由窗口读取，MCP 只读投影隐藏该字段。

帧使用整数 at/duration/frame，FPS 为 `{num,den}`；source_in/out/source_time 使用 `{value,scale}`，不能把帧数直接当秒。Clip 同时保存资源 ID 与真实全局 stream_index。序列 imported_results 记录已处理成片来源，在撤销外持久保存，以免重开重放已撤销的自动入轨。只改文件路径、名称、备注或布局不改变节目 content_version。

引用 `Reference` 包含 occurrence id/name、kind、target_id、resource_id?/sequence_id?/clip_id?、UTF-16 start/end、unresolved。kind 为六类资源或 source_marker/sequence_marker；使用候选的完整稳定归属，禁止重名时取第一个。单点合法，不要求出点，不创建零时长视频。删除或移出可用范围的绑定保留失效，使用前重新关联；改名同事务只同步已绑定正文。

节目 POST preview 冻结内容并生成缓存，GET preview 要求同版 version；导出使用相同已核验 MP4。项目切换取消旧请求、停止播放器并按 session/project/sequence 隔离查询，节目更新时不显示过期成片。AI frame-modifications 默认返回 501，不创建生成任务或调用服务商。

`GET /api/projects`、项目/可见集只读、旧脚本和 Workflow 的有效读取仍受当前工程约束。没有打开工程时，相关列表为空，直接对象访问不可用。旧项目库和逐项授权不是新界面的前置步骤。

## 3. 脚本、SkillRun、编辑和交付调用

### 3.1 SkillRun

1. 从当前 workspace 取得 project ID，从 skills 取得 Skill 版本/摘要，从当前媒体视图取得内容指纹；发起任务时选择 flow、execution_mode、goal、可选预设及 budget。
2. `POST /api/skill-runs` 使用 `SkillRunCreate`；`GET /api/skill-runs?project_id=...` 和 `GET /api/skill-runs/{id}` 读取状态。`/context` 读取固定 Skill/媒体和工具名单。旧 visible_set_sha 字段在兼容类型中保留，当前工程服务以当前资源/指纹处理，不要求界面逐项确认。
3. builtin_api 调 `/execute`；external_mcp 由 Agent claim/tool。HTTP execute/tool 为同步执行请求，状态另存 Go，不能假定断开后无限后台继续。
4. `/plan`、`/voice` 修改精确计划/声音；`/finalize` 定稿当前版本；`/resume` 用于非计划确认的待恢复状态；`/cancel` 取消。写入使用目标 expected_version，不把 plan.version 代替 run.version。
5. `/workbench` 给出双时间轴、预览和游标；`/edits` 绑定当前 artifact ID/SHA、plan_version、prompt 及互斥选择方式。`/checkpoints`、`/undo`、`/redo` 和历史 artifacts 为窗口人工历史入口。

局部修改的 segment_index 从 0 开始；at_seconds 是成片时间；区间须对齐完整片段边界，溶解重叠点可能选择两段。历史预览不作为当前编辑对象。新计划/声音清除旧定稿/检查，撤销不恢复调用许可、不退款/重置预算。

### 3.2 工作台脚本与声音

旧 script_id、SkillRun 的 run_id 和 `.avs` 文件 ID 分属不同契约，不能互相拼 URL。ScriptWorkbenchView 包含版本、解析文档、分段、实际旁白、媒体及声音；保存/生成/否决/定稿与 voice 参数见下方逐项 HTTP 和 Script* 类型。

脚本生成与查证、TTS/试听通过对应预设/全局服务设置调用；不再提交窗口人工 Token 或重复项目外发授权。ProcessingProfile 保存的是 token_env 名称，Provider 诊断的临时 Key 不会自动写入 Worker 环境。

### 3.3 MP4 / ASS / 验收

preview 和 delivery_variant 均绑定已导出的 run/revision、fixed input、spec/preset SHA、request_id 和 expected_version。202 表示新任务，200 可以是原请求或活动同输入任务复用，以各接口响应为准。status/invalidated/is_current 要联合判断，不能将历史成功自动选作当前节目。

ASS v2 另绑定 draft_version/style_sha256；字幕草稿只改样式/时间，原文由源 SRT 固定。字体目录、preview/variant 文件、ZIP 均通过登记的键读取。完整规范与哈希见[媒体协议详解](架构与功能详解.md#preview)及 [ASS](架构与功能详解.md#ass)。

人工 acceptance 仍只接受实际支持的 passed/failed 枚举、当前 expected_version 和 check_item；模板的 pending/blocked 不是此 POST 的新枚举，不能提交伪通过记录。

## 4. MCP Agent 与 Worker

### 4.1 外部 Agent 的 16 个工具

连接 `runtime_status.mcp_url` 或 desktop-session.json.mcp_url，使用 Streamable HTTP。客户端按协议提供 clientInfo.name/version，可带 `X-VAC-Agent-Source` 或 `_meta["vac/agentSource"]`。没有 stdio 入口，也不需要单独申请 Token。SDK 协商协议；已验证版本记录为 2026-07-28、2025-11-25、2025-06-18、2025-03-26。

| 工具 | 参数 | 返回/约束 |
|---|---|---|
| skills.list | `{}` | Skill 元数据和能力 |
| skills.get | `{id}` | 完整 Skill、version/content_sha256、资源索引 |
| skills.read_resource | `{id,resource,content_sha256}` | 固定包 SHA 下的文本资源，不接受磁盘路径 |
| projects.list | `{}` | 仅当前打开工程，没有工程则为空 |
| projects.visible_set.get | `{id}` | 当前工程媒体指纹/视图，只读兼容名称，不要求人工可见集确认 |
| resources.list | `{project_id}` | 当前导入资源，移除路径信息；不返回 removed 资源 |
| resources.read | `{project_id,resource_id}` | 文稿/字幕 text、脚本 view 或图片原生 ImageContent；源读取限 8 MiB，音视频改用媒体工具 |
| sequences.list | `{project_id}` | 当前工程序列概览；无人工历史 |
| sequences.get | `{project_id,sequence_id}` | 当前帧模型/session/revision/content_version；人工历史不返回 |
| references.list | `{project_id,sequence_id?}` | 带类型、归属和时间的候选；允许重名 |
| references.resolve | `{project_id,references}` | 稳定 ID 解析；失效引用返回冲突，不按同名替代 |
| skill_runs.create | RunRequest | 当前工程 external_mcp run；参数不是随意 actor/role |
| skill_runs.claim | `{run_id,expected_version}` | 当前会话领取符合角色/租约的外部 run |
| skill_runs.get | `{run_id}` | 本会话可读 run、固定上下文和 edit_request |
| skill_runs.cancel | `{run_id,expected_version}` | 取消本会话运行 |
| skill_runs.tool | `{run_id,request:{name,arguments,expected_version,idempotency_key}}` | 调用白名单内层工具，返回 run/result 或 isError |

`arguments` 必须为 JSON 对象，内层上限 128 KiB，包含 wrapper 的 HTTP 请求上限 256 KiB。传额外 actor/role/path 不增加权限。MCP 不提供人工定稿、resume、voice 许可、日志、历史检查点及 undo/redo。

### 4.2 内层 15 个工具

| name | arguments | 主要结果与约束 |
|---|---|---|
| timeline.read | `{sequence_id?}` | 默认发起序列，返回 session/revision/content_version；隐藏人工历史 |
| timeline.edit | `{sequence_id?,command:{session,expected_revision,idempotency_key,label,operations}}` | 只允许修改发起序列，Go 原子命令；history.undo/redo 拒绝，来源为 Agent |
| references.resolve | `{references}` | 解析带类型、对象和归属的引用；单点合法 |
| media.list | `{}` | 无磁盘路径的媒体 ID、asset_id、name、in/out、SHA |
| media.get_frames | `{media_id?,every?,interval_seconds?,threshold?,coverage_seconds?}` | 帧 ID/时间/摘要；every 1～30 默认 3，interval .25～30 默认 1，threshold .001～1 默认 .12，coverage 1～120 默认 15；超预算暂停，不静默截断 |
| media.transcribe | `{media_id}` | 词级 transcript 和 artifact；需要已配置服务，缺依赖停止并报告 |
| summaries.get | `{}` | 当前 summary 或 null |
| summaries.submit | `{model,narrative,beats,timeline}` | timeline 项含 media_id/start/end/description/confidence/frame_ids；confidence low/medium/high，必须引用同源窗口内真实帧 |

#### TL-14 · GET `/api/projects/{id}/resources/{resource}/loudness`

- 请求：query stream=真实全局音频流索引（非负整数）；可选 AbortSignal
- 成功响应：LoudnessEnvelope {ok,version:2,stream_index,duration,sample_rate:8000,channels,bucket_seconds,buckets,floor_db:-60,clip_db:-0.1,encoding:u8-dbfs,peak,rms,clipped_buckets}；peak/rms 为 base64 每桶一字节，按 dB 线性：0=不高于 -60 dBFS（显示为静音，正增益下也不会显示出来），255=0 dBFS（更高的值钳到 0 dBFS，负增益下真实超载不再提示削波）
- 行为：FFmpeg 流式解码 8 kHz PCM，不下混（保留原声道，最多 8 声道）；每桶 peak=各声道 max\|x\|（单声道满幅也会标记削波），RMS=各声道功率均值；桶宽 max(0.02s, 时长/200000)；按源 SHA256+loudness-v2+流索引缓存于 previews/；同一缓存计算中 409（前端退避重试 8 次，错误态每 30s 重新请求）；非音频流/资源失效 400
- 生命周期/接线：current_project_only；统一编辑器 / 序列音频轨片段音量谱
- SDK：`timelineApi.loudness(project:string, resource:string, stream:number, signal?:AbortSignal)`；[源码](../webui/src/timelineApi.ts:20)
- 后端：[HandleFunc](../control-plane/internal/api/timeline.go:108)

## DNG / Sony ARW 非破坏整图调整

沿用项目资源导入、PATCH、preview 和 content 接口，不另设平行导入流程。ProjectResource / ResourcePatch 新增可选 raw_develop：{exposure,white_balance,contrast,saturation}。exposure 为 -2～3 EV；white_balance 为 camera/auto/daylight；contrast 为 0.5～2；saturation 为 0～2。仅 DNG/ARW 接受该字段，所有数字必须为有限数值；字段存在时必须完整提供，非法 recipe 整体拒绝。导入时保存默认 {exposure:0,white_balance:"camera",contrast:1,saturation:1}，老 AVP 缺失该可选字段时采用同样默认值。

原始 Source.sha256 继续指向磁盘原片。RAW 的 content（包括普通请求）返回当前 recipe 的 PNG 派生图，首次需要先调用既有 preview 接口；不存在派生图时返回未找到，源发生变化时拒绝旧缓存。图像预览/缩略图、绘制和序列合成统一用当前 recipe；客户端 recipe 查询串仅用于刷新图片 URL，不参与服务端参数修改。绘制 image.resource_sha256 对 RAW 绑定有效内容版本，Go 私有 manifest 的 binding_sha256 与派生 PNG 实际 sha256 分开；普通图片保持原指纹兼容。参数随工程保存，Worker 及磁盘路径不交由模型输入决定。

| POST `draw-compositions/{composition}/preview` | `{session,content_version,request_id,frame,document}`；返回同请求PNG(base64)、geometry、帧、内容签名和WorkerPID。document可为未保存草稿，不改工程 |
| DELETE `draw-compositions/{composition}/preview?session=...` | 销毁当前会话拥有的持续预览；工程切换/退出自动销毁 |
| POST `draw-compositions` | 既有CAS/幂等参数；composition.document包含画布、sources、nodes、变量、主题、seed及图片配方。Go生成plan与内容版本 |
| POST `draw-compositions/{composition}/render` | `{session,content_version,format?}`，format默认mp4，可webm-alpha/prores4444；返回哈希、帧数、格式、alpha和环境签名 |
| GET `draw-compositions/{composition}/render?version=...&format=...` | 只读取匹配当前内容/素材/环境且哈希验证通过的文件 |
| POST `draw-compositions/{composition}/export` | render参数加绝对path；扩展名必须匹配格式，验证后原子复制，不将服务商凭据写入工程 |
| POST `draw-compositions/{composition}/import` | 既有session/content_version/sequence_id/expected_revision/idempotency_key；source_mode=snapshot（冻结）或follow（随源），无需先渲MP4；省略/rendered保留旧成片导入 |

`DrawDocument.schema_version=1`，canvas为偶数尺寸16..3840×16..2160、有理fps(1..120)、sRGB/straight alpha；最长300秒/18000帧，最多32来源/128节点。sources保存id/engine/source/reason及可选独立画布/帧率/长度；nodes保存稳定id、类型source/image/text/group/mask/shape、parent_id、来源/资源ID、半开帧范围、源偏移/有理速度、变换/透明度/层级/裁切/关键帧/参数。裁切单位像素；keyframes为严格递增局部frame/x/y/opacity。未知节点效果、循环、越源范围及项目外资源均失败。资源指纹、RAW配方与plan由Go生成。

MCP经`skill_runs.tool`注册`draw.capabilities`、`draw.preview`；preview只读取已保存构图的真实帧并消耗帧预算，返回可由artifacts.get读取的原生PNG。draw.render可选format；不接受Agent文件路径。draw.import仍限运行发起序列，完成使用结构化run.finish。技能/Worker不获得任意shell或自动下载能力。

SSE `workspace.draw.preview`携带project_id/session_id/composition_id/request_id/frame/phase（loading/compiling/updating）；前端按活动请求关联。查询及持久状态按project/session隔离；`workspace.draw_states`保存每个构图的head/node/source/tab/preview_only/output_format。Go源资源`draw_source={composition_id,mode,snapshot}`保存可编辑源，空磁盘路径不表示文件缺失。

人工绘制历史另有GET/POST `draw-compositions/{composition}/history`。POST包含session、expected_revision（工程）、composition_revision、idempotency_key及action=undo/redo，整体恢复一次已保存场景修改，修订始终递增；不回退运行、预算或冻结资源。Agent工具不暴露人工历史。当前打开会话保留最近32次场景修改，重开工程后历史清空；画面内容仍完整保存在AVP。

高清帧读取：artifacts.get对已验证frame支持最大16MiB PNG/JPEG，transcript维持256KiB；MCP返回原生image内容，文本结果不携带重复base64。大小上限不放开工程/运行范围、指纹或工具预算。

### QA-FISH 绘制进度与图片错误接口

- MCP `skill_runs.progress` 请求 `{run_id, expected_version, phase, output_chars?}`；phase 为 `working/generating/checking/rendering`，字符数为 0–4194304。仅当前工程的外部任务所有者可对 queued 任务上报；校验租约、版本、角色和冻结上下文。成功返回更新后的 `SkillRun`、刷新两分钟租约，不消耗步骤预算。30–60 秒内续租一次，后续操作使用响应版本；运行中工具与心跳不得并发写同一运行。
- `SkillRun.progress` 为 `{phase, output_chars, started_at, updated_at}`。`workspace.skill.progress` 是无凭据的 SSE 失效信号，前端使用 `GET /api/skill-runs/{id}` 读取权威状态；`workspace.draw.preview` 同样受当前工程过滤。内置运行的字符数来自本地 Worker 流式响应，只在生成期间存在。
- 服务商配置新增可选 `reasoning_effort`（OpenAI兼容格式：none/minimal/low/medium/high/xhigh）和 `max_output_tokens`（256–128000）；不保存凭据。绘制任务使用其剩余时限；Step 5 high 在未设置额度时默认48000。截断/超时分别对应任务原因 `model_output_truncated`/`model_request_timeout`。
- `draw.save` 的 `composition.images` 及 source 的 `image_bindings` 自动归一为 `document.nodes`；`document.images` 是无效字段，返回可定位的参数错误。引用未绑定的图片别名会明确失败。可修正绘制参数错误后任务保持 queued，Agent 取新版本并使用新幂等键再次提交。

以上接口于2026-10-27通过Go/MCP整包和真实可见桌面验证；包含所有权、租约、预期版本及工程切换边界。模型传输由本地模拟服务验证截断、超时和不完整流，不代替真实服务商模型质量验收。详细证据见[测试说明](../scripts/TESTING.md)。
