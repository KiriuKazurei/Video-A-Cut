# VAC 功能文档：模块职责与Agent开发约束

更新：2026-11-02。适用源码：`codex/integrate-remote-20261029`的当前0.3.3开发工作副本。

本文是Agent修改本项目时的功能合同：说明每个模块负责什么、已经具备什么、必须保持什么，以及哪些内容不应重复建设。它用于约束开发范围，不是终端用户操作手册，也不是新增功能清单。源码位置是定位入口，不是封闭文件白名单；完成已授权需求所必要的调用方、类型和检查可联动修改，但应说明依赖关系，不能借联动扩大产品范围。

[项目文档](项目文档.md)负责定位与沿革，[架构与功能详解](架构与功能详解.md)负责实现机制，[接口文档](接口文档.md)负责字段和协议，[计划文档](计划文档.md)负责当前工作，[TESTING](../scripts/TESTING.md)负责测试与证据。实际用户需求优先于本文；发现文档与源码不一致时先核对当前调用链，区分缺陷、兼容行为与已批准变更，不以过时说明为由回退新功能。

## 1. 全模块共同约束

1. **按需求修改。** 先明确本次要改变的可观察行为和涉及模块；只修改实现该行为、修复关联缺陷和维护合同必需的部分。无关改名、目录搬迁、风格重排、抽象层替换和顺带重构不计入任务。
2. **先找现有入口。** 在现有工作区、service、SDK、Worker和测试中查找实现。能扩展现有模块就不另建平行页面、第二套状态、第二个服务或独立运行器。确需新增时说明既有入口为何不能承载，不以新增本身为目标。
3. **状态归属唯一。** Go控制面管理当前工程和运行；已保存工程以AVP为依据。前端缓存、MCP适配、SQLite投影和Worker不能各自成为第二套业务权威。
4. **Agent自主完成流程。** 不重新添加每一步人工鉴权、定稿、审批或专门验收页面/选项。用户查看、编辑、取消及已有配置入口保留；任务归属、预算、版本校验和取消语义不能因去除人工门槛而被删除。
5. **不擅自增加能力。** 不因“更完整”增加服务商、引擎、导出格式、联网安装、自动下载、遥测、后台轮询、警告弹窗或配置项。已有明确需求所需的能力按对应模块实现，非必需项留在计划中。
6. **保存与原件分离。** 保留未提交输入、用户自定义配置、原始媒体和其他工作树修改。缓存和派生物不能覆盖源文件，打开旧格式不能等于自动迁移写盘。
7. **复用验证体系。** 更新受影响的既有测试、固定样本和文档，不按任务另建重复套件；只运行能证明本次改动的适用检查。工程通过、真实运行、模型质量与人工认可分别记录。

## 2. 模块边界速查

| 模块 | 负责 | 不承担 |
|---|---|---|
| 工程 | 当前AVP、保存、恢复、切换 | 新项目数据库或媒体复制仓库 |
| 工作区壳层 | 路由、菜单、焦点、导航 | 各工作区业务状态 |
| 资源与导入 | 当前工程资源及受控媒体准备 | 第二套素材库或任意磁盘代理 |
| 脚本 | 创作要求、分段、引用、保存和交接 | 新Agent客户端或独立剪辑引擎 |
| Agent/Skill | 上下文、工具执行、预算和任务生命周期 | 逐步人工审批或任意shell执行 |
| 时间线 | 多轨编辑、序列事务和节目模型 | 另一套独立媒体合成规则 |
| 绘制 | 可编辑构图、图层和程序化像素 | 图像模型生成/修改服务 |
| 配音字幕 | 声音、字幕及其派生产物 | 重复服务商配置和全局许可 |
| 预览交付 | 同版合成、登记、质量提示和下载 | 专门验收流程或外部剪辑软件 |
| 配置与运行准备 | 预设、服务引用和依赖检查 | 隐式部署、付费调用或模型下载 |
| 状态诊断与历史 | 观测、故障定位、可追溯编辑 | Agent思维观测或第二控制面 |
| 桌面宿主 | 原生集成、监督和更新 | 业务编排或浏览器伪造原生能力 |

## 3. 工程与保存恢复

**职责与已有能力：** 一个窗口围绕一个当前AVP工作副本；新建、打开、最近、保存、另存、关闭、缺失引用及恢复。写AVP3/AVS2，兼容读旧格式；原子保存及定时恢复副本。SQLite维护配置/运行索引和投影。

**复用入口：** `control-plane/internal/service/project_workspace.go`、`project_history.go`、工程模型及`webui/src/projectWorkspace.tsx`；字段以工程合同为准。

**必须保持：** 正式文件和未保存副本分开；工程会话切换拒绝旧请求；保存失败或取消不丢草稿、不切走；另存身份及资源归属一致；工程不存云服务密钥；打开不改原件。

**开发限制：** 不新增第二套项目列表/数据库保存入口，不把缓存或EDL替代AVP，不默认复制/改写全部媒体，不把恢复副本变成静默覆盖。

**修改联动：** 格式变化检查读旧/写新、另存、恢复、资源绑定与MCP隔离；沿用工程相关套件，不只证明JSON能解析。

## 4. 工作区、菜单与导航

**职责与已有能力：** 资源、独立脚本、编辑、绘制、导出、TTS、设置；文件/编辑/视图菜单、快捷键、当前对象路由和草稿保活。旧脚本链接进入脚本；旧审查/验收链接进入编辑。

**复用入口：** `webui/src/navigation.ts`、`webui/src/workspaces/`和现有菜单组件。

**必须保持：** 工作区共享当前工程；文本输入焦点优先；导航不丢未提交修改；设置/TTS不强加录像流程下一步；成片直接在编辑页检查。

**开发限制：** 不恢复独立审核验收页面、选项和确认按钮，脚本按2026-11-02用户要求位于可调宽右侧栏，不复制第二份脚本状态，不为已有功能复制顶栏入口或平行向导，不为页面方便新建一套工程状态。

**修改联动：** 校验旧链接、快捷键、返回路径、窄窗口及切换草稿；界面变更使用既有浏览器覆盖，不以端口在线代替窗口证据。

## 5. 资源管理与录屏导入

**职责与已有能力：** 视频/音频/图片/字幕/文稿/脚本六类资源；筛选、备注、预览/代理、入出点、缺失重定位。录屏探测真实流、选轨、选段、拆分/合并、受控准备和恢复。

**复用入口：** `project_resources.go`、`ingest*.go`、`ResourcesWorkspace.tsx`、`ResourceBin.tsx`及已有导入Worker。

**必须保持：** 稳定资源ID与源指纹；导入仅作用当前工程；移除引用不等于删除原件；不跨未选间隙合并；资源预览入出点与运行冻结范围不混用；执行身份/租约/进程归属和取消继续有效。

**开发限制：** 不新建独立素材仓库，不按同名自动替换素材，不任意扫描用户目录，不把界面标记静默应用为所有转录/生成裁剪范围，不通过按进程名结束进程替代所属执行回收。

**修改联动：** 校验流索引、源时间、路径变化、缺失/重定位、取消恢复和工程隔离；复用固定媒体，不拿用户原件当可再生测试输出。

## 6. 脚本工作台与Agent交接

**职责与已有能力：** 编辑器右侧栏承载脚本工作台，宽度可拖动/键盘调整并记忆；顶栏脚本入口打开同一编辑上下文，收起/切页保留同一实例，辅助标记折叠；空工程新建、多脚本选择、标题/正文/分段编辑、保存/AVS导入导出、内部模型生成与停止、声音设置和历史。复制Agent任务前保存最新脚本；Agent通过`resources.list/read`读取对应资源后执行。

**复用入口：** `project_scripts.go`、`script_workbench.go`、`script_references.go`、`script_runtime.go`、`ScriptWorkspace.tsx`、`ScriptWorkbench.tsx`和`ScriptAgentHandoff.tsx`。新建复用资源POST的`{kind:"script"}`，不另建创建协议。

**必须保持：** 正文是创作要求，旁白属于分段；空行分段和特殊语法继续有效。引用绑定稳定ID，重名明确消歧，失效不按名称替换。先保存再派发/交接，使用返回修订；冲突保留输入且不交接旧稿，迟到结果不盖新稿。已有路径保存AVP，无路径仍需正常另存才能跨重启恢复。

**开发限制：** 不增加人工定稿/否决按钮，不把“保存脚本”变成启动生成，不复制另一套语法解析器或脚本数据库，不把任务复制成功写成已向外部客户端派发，不把内部模型调用配置复制到Agent交接组件。

**修改联动：** 检查空工程创建、保存重开、脚本切换、真实MCP读取、修订冲突、导航草稿与取消；语法/绑定变化同步Go、前端、Worker及现有运行时语法合同。

## 7. Agent与Skill运行

**职责与已有能力：** 外部MCP/内置API两种执行方式，共享Skill、上下文、预算、工具和产物。lightweight、visual_heavy、自定义组合，以及video-use/绘制包；支持计划/配音编辑、步骤诊断、自助恢复与直接时间线编辑。

**复用入口：** `skill_runs.go`、`skill_tools.go`、`skill_agent.go`、`skill_*.go`、`control-plane/internal/mcpserver/`和现有Skill清单/工具合同。

**必须保持：** 固定Skill摘要、工程/脚本/媒体快照和预设版本；所属任务、角色、租约、幂等、CAS和预算生效。计划按实际Agent身份确认并继续；参数/上下文错误可修正。取消为终态，恢复不退款或重置消耗；MCP不得冒充人工质量认可。局部修改使用当前成片ID/摘要和计划修订定位；scripts.propose与plan保存共用范围校验，未选片段正文/媒体/旁白/配音配置保留，选区内指令只允许在段落数量不变时更新。不得用完整plan保存绕过局部范围。

**开发限制：** 不在工具间插入逐步人工审批，不为内外Agent分别维护两套工具语义，不把Markdown编译成第二套固定工作流，不新增任意shell/文件读取工具，不因纠错去掉真实工程与版本隔离。旧兼容代码存在不等于需恢复旧UI。

**修改联动：** 协议改动核对外部MCP、内部模型循环、包声明/嵌入资源、错误恢复、取消及预算；沿用服务/MCP/实际媒体覆盖，不以模型桩证明真实模型质量。

## 8. 多序列与时间线编辑

**职责与已有能力：** 多序列、真实流展开、多轨/链接组、移动/修剪/分割/复制/波纹/空隙、轨道状态、常用效果、恒定变速、增益关键帧、字幕、标记及撤销重做；源/节目监视器和Agent轨组对照。

**复用入口：** `project_timeline.go`、`sequence_preview.go`、`SequenceTimeline.tsx`、`TimelineInspector.tsx`、`workers/node/timeline-cli/src/sequence.mjs`和统一时间线合同。

**必须保持：** 整数帧/有理FPS和真实音轨索引；事务整体成功或失败；锁定、轨道范围、链接选择、标记跟随及稳定引用；人工与Agent使用同一编辑引擎，Agent不能调用人工历史撤销。原轨与Agent成片组并存，不覆盖人工剪辑。轨组仅作对照范围，不作为锁或跨兼容轨移动的限制；联动音轨随主片段进入目标轨组，插入模式仅波纹目标组。视频轨可混排普通视频、渲染成片与可编辑绘制源；音乐、配音以及已拆分或联动的音频片段可在不同音频轨间移动。视频/音频类型保留，不支持音画跨类型落轨或自动抽音。两类轨共用跨组移动、联动流、预留锁与手动锁规则。

**开发限制：** 不为Agent单建隐藏时间线，不在前端直接改数据库或另算持久化序列，不按名称或数组顺序代替实例ID，不让预览/导出解释不同效果，不把任意ASS动画声称为原生效果。

**锁定规则：** 仅手动按钮或Agent明确发起的渲染/插入预留使用同一track.update locked状态；lock_owner仅记录触发者。Agent可向自己的锁定轨插入，不能覆盖或解除手动锁/其他任务锁。绘制导入支持target_track_id与at；插入后Agent显式解锁，失败/取消/结束兜底仅释放本任务锁。锁图标与状态即时一致，单纯渲染预览不自动锁轨。

**节目预览规则：** 无同版成片时优先生成播放头当前帧，再生成整段可播放预览；已有同版且哈希有效的MP4时直接取帧。当前帧使用每活动序列的常驻Worker与共享浏览器，绘制源仅寻所需源帧；复用sequenceGraph产生的同一有效片段、效果与字幕计划，由WebGL2完成层叠、裁切、缩放、位置、黑白淡入淡出和溶解，ASS继续复用原字体/样式。GPU不可用、上下文丢失或能力不足时回退现有CPU后端，并返回实际backend/renderer/hardware_accelerated/fallback_reason；软件WebGL不能标成硬件GPU。正式导出仍走完整合成及质量检查，不因预览命中缓存而省略。

**缓存与生命周期：** 源帧与合成帧共用64MiB PNG字节LRU，每序列最多4个绘制宿主、一个共享浏览器；仅修改位置/效果时复用未变源像素，源码/图片绑定变化只失效相关资源，其他工程不得共享Worker。当前请求优先，后台单路预取前后最多2秒、各不超过60帧；新请求停止旧预取，达到缓存水位停止扩充。拖动合并请求，迟到帧不得覆盖新位置；取消一次寻帧不销毁已编译环境，离开编辑器/切换序列显式释放，工程关闭/服务退出统一释放，闲置60秒退出。整段生成不随拖动重启；视频定位就绪后接管静帧，进度提示不得遮住已生成画面。前端不另保留整批大PNG查询缓存。静帧不代表完整音画检查或实时30fps；连续音画播放、硬件解码和代理质量属于第二步，不得提前写成已具备。

**修改联动：** 校验事务/撤销、音画映射、标记绑定、轨道范围及实际合成；显示优化不能改变媒体时间或内容版本。

## 9. 程序化绘制

**职责与已有能力：** 统一构图/图层/播放头、用途预设、关键帧、HTML/GSAP与React/Remotion源码；图片实例和RAW非破坏调整、源码检查/取帧/渲染、透明合成、渲后入轨及源快照/跟随入轨和共享终渲。

**复用入口：** `project_draw.go`、`skill_draw.go`、`draw_preview.go`、`DrawWorkspace.tsx`及Node既有draw/unified-draw运行模块。

**必须保持：** 构图源留在AVP；资源ID/源摘要与多实例分离；工程/构图修订、内容指纹、关键帧和整场景撤销；公共帧时钟及同版预览/导出。源码检查/沙箱边界不宣称操作系统级隔离；渲后MP4不是可还原图层。

**开发限制：** 不擅加Motion Canvas等新引擎，不将源码绘制扩成图像模型生成/修补，不为每引擎新增独立工程或时间线，不因追求实时增加默认常驻轮询/不受控并发，不以延长超时代替性能修复，不静默下载浏览器。

**修改联动：** 核验双引擎、透明/层序、图片绑定、当前帧、源入轨/共享终渲、取消和原件保留；长构图性能需同口径测量，不能用短夹具关闭60秒性能问题。

## 10. 转录、配音、字幕和混音

**职责与已有能力：** 本地faster-whisper/已配置云端词级转录；SAPI/StepFun TTS、试听、不可变声音模板与逐段设置；SRT、ASS派生/样式编辑、声音偏移/EQ/混音及时间线字幕。

**复用入口：** `tts*.go`、`script_voice.go`、`skill_voice.go`、`subtitle*.go`、`TtsWorkspace.tsx`、Python模型适配及Node字幕/音频合成。

**必须保持：** 本地模型显式目录/设备/精度及源时间映射；声音模板固定版本，升版不静默重绑；源SRT正文与派生样式分离；字体真实存在；实际音轨、偏移与字幕时码一致。

**开发限制：** 不在缺依赖时静默切云、换声音或设备，不自动下载模型/字体，不在每个页面重复云配音许可和服务配置，不用试听成功替代全片混音，不将通用人声模板界面扩为另一套脚本编辑器。

**修改联动：** 转录检查词级时间和源偏移；配音检查固定模板与真实声音；字幕检查草稿/样式摘要、字体、时间和实际帧；沿用现有语音/字幕套件。

## 11. 预览、交付与技术质量检查

**职责与已有能力：** 源/节目预览、独立MP4任务、脚本/Skill成片、MP4导出、XML/OTIO及媒体/音轨/字幕交付、ASS派生产物、登记下载和黑屏/静音提示。

**复用入口：** `sequence_preview.go`、`script_delivery.go`、现有preview/subtitle服务、`DeliveryPanel.tsx`、`ScriptDeliveryPanel.tsx`及Node timeline/export Worker。

**必须保持：** 产物绑定精确修订、输入摘要、规格/样式及文件哈希；同内容预览/导出共享合成和在途结果；旧成功不冒充当前。技术质量区分passed/failed/not_checked，警告不阻断用户交付；检查不伪称人工观感认可。

## 16. Agent修改前后自检

开始修改前，在现有计划中写清目标行为、受影响模块和现有复用入口。对新增页面、状态、接口、配置项、依赖、轮询或测试入口，先回答现有机制为何不能满足；缺少实际需求或证据时不新增。不把这个检查做成产品里的审批页，也不为正常修复增设用户确认流程。

完成时按实际改动核对：是否改变了合同外行为；是否出现重复入口/双重状态；原有保存、取消和版本语义是否保持；受影响调用方/类型/文档是否同步；运行了哪些适用检查，哪些未执行。只报告有证据的结果，不用代码量、测试数量或新增抽象表示完成度。

本文随功能边界变化维护，不按每次任务追加一套规约。计划与历史记录不能反向授权无关重构；用户明确改变模块目标时同步本文，避免旧约束阻断已授权的新工作。
