## 落地选择

新项目计划使用 run/计划历史，旧 scripts/0019 保留；新前端读 SkillRun.plan，不做未经定义的两套脚本双写。媒体工具首版使用原工作台的受控直接进程，而旧队列任务继续走原 Worker；同步 execute 请求在断连/取消时停止，不声称脱离请求后自动后台完成。两条路径共用解析、TTS 与 Node 渲染器。

转录是预设可选能力，纳入预设 SHA、外发许可及 run 显式授权；外部 MCP 可使用 builtin 视觉/解说加 transcription 的预设而无需 VAC 推理 Key。内置 Agent 常规推理走 narration，带实际图像时走 vision。
