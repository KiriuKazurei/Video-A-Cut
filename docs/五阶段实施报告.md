## 配置

启动流程的请求必须带 `content_mode`：`configured` 或 `builtin`。缺省直接失败。`builtin` 会记在流程上，界面标明它不是模型识别。资产须对 Agent 可见、未锁定，且 `allowed_agents` 包含 `recognizer`、`narrator`、`exporter`。已导出资产会先走现有 `ReopenAsset`，再绑定所选修订，不覆盖旧验收记录。
