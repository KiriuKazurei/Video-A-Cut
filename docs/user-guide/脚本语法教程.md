# VAC 脚本语法教程

适用于 VAC 0.5.1 的脚本语法 v3。你可以用普通文字说明想剪什么，再加上素材引用、字幕和转场。如果时间线上已有代码条，也可以直接写指令控制它的缩放、位置和音量。

## 1. 写第一段脚本

打开顶部的「脚本」入口，在工作台新建或选择一个脚本。把下面两段粘贴到正文，保留中间的空行。

```text
先展示操作前的画面，用一句话介绍本次演示。{"操作演示"}

展示操作后的结果，说明画面里最明显的变化。{交叉溶解}
```

空行会把普通脚本分成两段。每段的普通文字是**创作要求**。如果你希望按某句话配音，把那句话填入相应分段的「实际旁白文稿」。双引号字幕 `{"操作演示"}` 会指定画面上显示的文字。

点击「保存脚本」保存草稿。需要生成文稿时，可以使用已配置的内部模型，或者把任务交给已连接 VAC 的 Agent。分段文稿和素材齐备后，可以点击「生成成片与 Premiere 包」。

## 2. 指定素材、字幕和转场

| 想做什么 | 写法 | 使用说明 |
| --- | --- | --- |
| 引用素材或标记 | `{@操作演示.mp4}` | 先把素材导入当前工程，再用工作台候选选中正确的素材或标记。示例名换成你工程中的识别名。 |
| 使用动效镜头卡 | `{#card-stack}` | 输入 `{#` 后按卡号或画面描述搜索。每段或每个代码条可选一张卡，正文继续说明文案、素材和动作。 |
| 整段显示一句字幕 | `{"操作步骤"}` | 每段最多一条这种简写字幕。 |
| 指定字幕字号、字体 | `{"操作步骤", 字号:36px, 字体:"Microsoft YaHei"}` | 字号可取 1–512px。字体用已安装的字体族名，样式字段可省略。 |
| 只在指定时间显示字幕 | `{字幕, 文本:"结果", 时间:条内1s, 持续:2s}` | 从当前段或代码条的第 1 秒开始显示 2 秒。可写多条，可加字号和字体。 |
| 从黑色或白色淡变 | `{黑屏}` 或 `{白屏}` | 用在本段入口。 |
| 与上一段叠化 | `{交叉溶解}` | 从上一段过渡到本段。每段只选一种入口转场。 |

同名素材或标记出现时，请在候选里确认类型和所属素材。引用显示失效时，先重新关联，再生成或渲染。普通脚本每段生成时只选用一个视频源。要明确换另一个视频，用空行另起一段。

例如 `{#card-stack}依次弹出三张功能卡，使用当前产品的功能名。`。要指定镜头卡的一个变体，可写 `{#chart-live-moves/axis-rescale-shock}`。保存后交给绘制 Agent，检查代码轨中的实际画面，再从时间线导出。

字幕文字用英文双引号包住。引号里的逗号、冒号和花括号会照原样显示。字幕里要显示双引号，写 `\"`。正文里要显示字面花括号，写 `\{` 和 `\}`。

## 3. 在代码条上控制画面

在时间线上选中已有的代码条，再编辑右侧工作台。代码条对应一个片段，空行会保留在文本里。只改下面这类参数，保存后即可预览。要改标题设计、构图或动画内容，再修改普通描述并显式重新生成对应代码条。

下面适用于长度至少 3 秒的代码条。合并进现有文字时，保留其他指令，并检查原文是否已有相同时间的缩放。

```text
{缩放, 时间:条内1s, 比例:120%}
{字幕, 文本:"开始，{原样}", 时间:条内1s, 持续:2s, 字号:24px}
```

从代码条的第 1 秒开始，画面立即放大到 120%，字幕显示到第 3 秒。如果要让缩放在半秒内逐渐完成，可以在缩放指令中加 `持续:500ms`。

| 仅代码条可用 | 示例 | 效果 |
| --- | --- | --- |
| 音量 | `{音量, 增益:-6dB}` | 调整此代码条自带的声音。独立音乐或旁白请到相应音轨调整。范围 −96 至 24dB。可加 `起始增益`。 |
| 移动 | `{移动, x:100px, y:0px, 持续:1s}` | 在 1 秒内移动到相对画布中心右侧 100px 的位置。x、y 都要填。 |
| 旋转 | `{旋转, 角度:30, 持续:1s}` | 在 1 秒内转到顺时针 30 度。角度直接写数字。 |
| 缩放 | `{缩放, 比例:120%}` | 设置整幅画面的缩放比例。范围 1%–800%。 |
| 透明度 | `{透明度, 从:0%, 到:100%, 持续:500ms}` | 在半秒内从完全透明变为完全不透明。范围 0%–100%，起始值 `从` 可省略。 |

## 4. 读懂时间写法

| 写法 | 从哪里计时 |
| --- | --- |
| 省略 `时间` | 当前段或代码条的起点。 |
| `时间:条内1s` | 从当前段或代码条起点往后 1 秒。 |
| `时间:条内500ms` | 从当前段或代码条起点往后半秒。 |
| `时间:条内30f` | 从当前段或代码条起点往后 30 帧。实际秒数取决于帧率。 |
| `时间:序列00:00:10:00` | 从整条时间线起点计的时码，最后两位是帧号。旧写法 `时间:00:00:10:00` 也按序列时间解释。 |

例如，一条代码条从序列第 8 秒开始。要让字幕在序列第 9 秒出现，可以写 `时间:条内1s`。如果之后把代码条移到序列第 12 秒，字幕仍会在条内第 1 秒出现，也就是序列第 13 秒。

`持续` 可以用 `s`、`ms` 或 `f`。字幕省略持续时间时显示到段尾或条尾。代码条的动画省略持续时间时立即切换，填写后按线性变化。

## 5. 出错时先查这几项

- **提示指令或字段未知。** 普通脚本只写引用、字幕和转场。缩放等参数请在代码条中填写。写到一半时，可以从工作台的补全候选中选择，按 Tab 或 Enter 接受。
- **提示时间越界。** 检查开始时间加持续时间是否超过段或条的结尾。例如，2 秒长的代码条从第 1 秒起只剩 1 秒可放字幕。
- **提示重复或重叠。** 同一属性的动画不能在同一时刻重复，也不能互相重叠。不同属性可以同时动画，多条定时字幕也允许重叠。
- **保存后画面没变化。** 看工作台是否报了行列错误。无效的代码条文本可能作为草稿保留，画面继续显示上一次有效结果。修正并保存后，再到节目预览检查。
- **找不到字体或素材。** 换用本机已安装字体，或在工作台重新关联实际导入的素材，再生成。
