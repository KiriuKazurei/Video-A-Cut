## 2. 用户工作路径

1. 新建或打开AVP，确定保存位置；导入视频、音频、图片、字幕、文稿或脚本，也可从空工程开始绘制。
2. 在独立脚本工作区新建并保存创作要求。引用素材、片段或标记时选择确切对象，必要时编辑分段旁白。
3. 选择外部MCP Agent或已配置的内部模型。外部Agent复制任务后读取最新脚本；内部模型先保存再生成。缺依赖明确报告，不静默下载、切云或更换模型。
4. Agent按Skill读取证据、编排并直接执行编辑；可用lightweight、visual_heavy或自定义组合，也可使用绘制管线。计划和修订由工具绑定，不要求人工逐步确认。
5. 在编辑页查看节目、试听、修改时间线或比较独立Agent轨组。绘制源保留可编辑性，渲后视频也可参与混剪。
6. 导出MP4或Premiere交付包；需要外部精修时实际核对XML/OTIO、音轨、字幕、切点及重链接。机器质量提示不代替人工观感。
7. 保存或另存工程，切换和退出时处理未保存内容与在途任务。迁移时保留外部媒体依赖。

各功能模块的职责、不变量、现有复用入口及修改限制统一见[功能文档](功能文档.md)，Agent开发前须核对所涉模块，避免重复建设和无关扩展。

## 3. 总体架构与技术栈

```mermaid
flowchart TD
  UI[React 工作区与文件菜单] -->|REST / SSE / Range| GO[Go 控制面与当前工程副本]
  DESKTOP[Tauri 原生窗口与文件集成] --> UI
  DESKTOP -->|监督启动与停止| GO
  AGENT[外部 Agent] -->|本机 MCP| GO
  GO <--> AVP[AVP / AVS 文件与恢复副本]
  GO <--> DB[SQLite 全局配置与运行投影]
  GO --> PY[Python 模型 / 转录 / TTS / 导入 Worker]
  GO --> NODE[Node 时间线 / 预览 / 导出 Worker]
  PY --> FFMPEG[FFmpeg / ffprobe]
  NODE --> FFMPEG
  FFMPEG --> OUTPUT[MP4 / XML / OTIO / 音轨 / 字幕 / 交付包]
```

| 层 | 技术及来源 | 职责 |
|---|---|---|
| 控制面 | Go `1.26.1`，net/http，modernc SQLite，官方 MCP Go SDK；版本见 [go.mod](../control-plane/go.mod) | 唯一业务服务层、事务、运行和文件归属、工具执行与发布 |
| 前端 | React 19、TypeScript、Vite 7、Ant Design 5、TanStack Query；见 [package.json](../webui/package.json) | 资源/脚本/编辑/绘制/导出/TTS/设置；「绘制」是少开顶栏分页的显式例外。菜单、表单/草稿、播放器、查询和事件失效 |
| 桌面 | Tauri 2/Rust，WebView2；[锁定依赖](../desktop/Cargo.toml)、[工具链](../desktop/rust-toolchain.toml) | 窗口、文件/剪贴板、单实例、后台进程、下载与更新 |
| Python | Python 3.11+ 与 `vac_worker`；可选依赖显式准备 | 媒体导入、模型协议、转录、声音和内容阶段 |
| Node | Node ≥22.12，timeline-cli、export-worker | 时间线规范化、格式适配、预览、ASS、脚本渲染和任务提交 |
| 媒体工具 | 已安装 FFmpeg/ffprobe，字体、Windows SAPI；云端能力按配置 | 编码、抽帧、探测、字幕、音频与实际文件生成 |

已保存工程以 `.avp` 为依据；Go 管当前工作副本；SQLite 保存当前工程可编辑投影、运行索引、恢复与全局配置。EDL 是媒体编排与交付契约，不能把它、SQLite 或旧 `project.json` 当成第二套工程保存入口。

## 5. 开发、运行与构建

Windows使用已安装PowerShell 7及UTF-8，保留profile。先按锁文件显式准备Go、Node、Python、FFmpeg/ffprobe、Rust/MSVC和WebView2；运行程序不会自动下载模型。以下命令在**选定源码根**执行，不能在旧工作树运行后当作新候选。

```powershell
pwsh -File scripts/Start-VideoAutoCut.ps1 -DataDirectory 'E:/VideoAutoCutData' -DevelopmentBuild
pwsh -File scripts/Stop-VideoAutoCut.ps1 -DataDirectory 'E:/VideoAutoCutData'
```

这是本机业务监督器入口；Vite浏览器预览不能替代桌面窗口。桌面工具链、启动及打包以`desktop/`配置和构建脚本为准，配置示例见[desktop.example.json](../desktop/desktop.example.json)。预构建程序须配对控制面、runtime清单、前端、Worker、contracts和Skill；单个旧二进制不代表当前完整应用。

```powershell
pwsh -File scripts/Build-TauriDesktop.ps1
pwsh -File scripts/Build-TauriDesktop.ps1 -Installer
```

打包需同版完整资源和明确签名配置；运行这些命令不会自动获得发布授权。测试入口、依赖和输出规则只维护于[TESTING.md](../scripts/TESTING.md)。本轮文档整理未启动桌面、调用模型、构建安装器或发布。
