## 启动及贯通顺序

使用已经核对过的 WebUI 构建。实际 profile 准备好后，在仓库根目录运行：

```powershell
pwsh -NoProfile -File .\scripts\Start-LocalPipeline.ps1 `
  -ProfileFile '实际服务商profile的绝对路径' `
  -IngestRootsFile 'E:\AI\Video Auto Cut\.run-data\manual-acceptance-preparation-20261002-125347\ingest-roots.local.json' `
  -Port 8806
```

ProfileFile 必须换成实际配置，不能照抄占位字符串。脚本创建独立会话，不下载或启动模型；新部署 profile revision 必须为 1。端口冲突按启动检查处理，不结束既有服务。

在 WebUI 中使用根 `acceptance_recordings` 和相对文件 `2026-06-07 04-10-16.mkv` 登记，完成治理授权后开始导入。操作路径：探测/选轨 → 分段/编辑选择 → 绑定实际预设准备 → 条件预检/启动 → 证据和场景确认 → 排序与草稿编辑/批准 → 语音/字幕/混音/导出 → 预览/试听/下载 → Premiere 精修验收。
