## 本地使用与统一验收

先按 [六阶段开发文档](六阶段开发文档.md) 配置所选 profile 和实际模型/声音，按 `configs/phase7/ingest-roots.example.json` 准备可读取的本地目录配置；本机已有 go/python/node/ffmpeg/ffprobe 与所需 TTS。启动示例：

```powershell
npm --prefix webui run build
pwsh -NoProfile -File scripts/Start-LocalPipeline.ps1 `
  -ProfileFile 'configs/phase6/profile.builtin.example.json' `
  -IngestRootsFile '本机已配置的根目录JSON绝对路径' -Port 8806
```

示例 builtin 用于本地闭环及诊断；实际内容模型选择 configured 预设并部署匹配配置。脚本不下载模型，配置不含凭据值。启动输出当前会话目录/日志和停止文件；监督只重启出错角色，停止只处理验证过的本次进程。

[统一人工验收计划](全项目统一人工验收计划.md) 保持后推：用同一候选版本、固定模型/声音及用户指定录屏，从导入到 Premiere 一次贯穿验收，包括真实内容判断、编辑/撤销/重跑和异常恢复。自动浏览器检查已经补齐工程证据，人工时重点核对真实内容与体验。
