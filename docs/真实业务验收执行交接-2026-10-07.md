## 4. 现有接口复用

实际启动示例使用现有入口，所有文件路径必须替换为已准备好的实际文件：

```powershell
pwsh -NoProfile -File 'E:\AI\Video Auto Cut\scripts\Start-LocalPipeline.ps1' `
  -ProfileFile '<实际profile文件的绝对路径>' `
  -IngestRootsFile '<受控录屏根配置文件的绝对路径>' `
  -Port 8806
```

该脚本要求新会话 profile revision 为 1；不要修改现有业务 profile 历史去满足示例。端口占用时另选空闲端口。外部模型权限使用现有 profile consent 流程；启动脚本不会代替人批准素材外发。

交付/预览使用现有 `/api/workflows/{run}/delivery.zip`、`POST/GET /api/workflows/{run}/previews`、`GET /api/previews/{id}` 和受控 files 路由。人工记录沿用 `GET/POST /api/workflows/{run}/acceptance`，POST 包含 `expected_version`、六个既有 check_item 之一、passed/failed 和 note；冲突先重读，不盲重试旧版本。
