## 多工作区统一测试

本轮所有生成物都在原根目录 `.run-data/tests/0.1.1/`；custom 的 WorkingDirectory 指向实际 develop 源码。示例：

```powershell
$managerRoot = 'E:\AI\Video Auto Cut'
$sourceRoot = Join-Path $managerRoot '.run-data/worktrees/agent-develop'
$testArgs = ConvertTo-Json -InputObject @('test','-p','1','-count=1','-run','TestScriptWorkbench','./internal/service') -Compress
pwsh -NoProfile -File "$managerRoot/scripts/TestWorkspace.ps1" -Action Run -Suite custom -Executable go -ArgumentsJson $testArgs -WorkingDirectory "$sourceRoot/control-plane"
```

Python 使用 -B；Node 使用现有依赖，不重新下载浏览器。类型检查不生成文件；Vite 的 outDir 必须显式放进 VAC_TEST_OUTPUT 对应管理目录。TEMP/TMP/TMPDIR、Go/npm 缓存和 Python 禁写缓存由统一入口设置。独立工作区自带的内置 suite 只测试其自身源码；不要把根目录旧代码的检查结果当 develop 证据。
