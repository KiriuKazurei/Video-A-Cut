# 验收缺陷修复与复检

本轮用户授权助手直接修复缺陷并执行剩余可自动操作验收。约定范围内的检查已通过，未发现尚未关闭的阻断问题。正式服务继续保留在 http://127.0.0.1:8806/，刷新页面可加载新界面。

## 修复内容

- 补齐已选片段的手动拆分、相邻合并和移除；不允许跨未选中间隙合并，拆分后仍验证最短一帧、片段数量和总时长限制。
- 派生片段独立显示，可编辑、保存、刷新恢复；重新分析时重建选择编辑状态。
- 选段或帧率存在未保存修改时，阻止生成旧选择版本。
- 时间格式完整保留微秒，消除边界往返编辑时的精度丢失和秒数舍入到 60 的显示问题。
- 修复长片段编号造成的窄屏横向溢出。
- 修复非整帧边界的 CFR 补帧时长错误计入来源录像范围：输出时间线保留实际整帧时长，来源终点受原选段边界约束。
- 浏览器验收每次构建当前控制服务，并为供应商模拟测试创建独立证据目录，避免沿用旧二进制或覆盖旧证据。

## 验收范围

本轮使用独立 headless Edge / CDP 实际页面操作及键盘事件，没有原生 computer use 或内置浏览器接管能力。真实 OpenAI 与 Premiere、迁移重链接及新版视听结果沿用用户已明确通过的记录；不把历史通过记录自动写到其他导出修订。Anthropic / Gemini 真实服务按用户决定不测试，本地模拟通过不代表真实供应商实测通过。

构建的既有 npm 配置与 React Query 指令提示、Python 测试夹具资源关闭警告未造成测试失败。此报告表示上述测试范围内未发现未关闭缺陷，不声称任意服务商、输入素材或机器环境均已穷尽验证。
