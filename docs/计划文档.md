## 4.1 成片两条思路（并列）与 Agent「绘制」路线

VAC 成片按**两条并列思路**规划，不是主从关系：

| 思路 | 名称 | 要点 | 当前状态 |
|---|---|---|---|
| 一 | 基于已有视频剪辑 | 素材轨 / 脚本与 EDL / FFmpeg 成片 / Premiere·OTIO 精修交接；轻量流程走 video-use 剪辑面，画面流程走 visual summary + 编排 | **现行主线**（已落地与持续打磨） |
| 二 | Agent 直接生成/「绘制」画面 | Agent 主动调用绘制类 Skill，用程序化构图产出视频像素（动效、字幕层、UI 演示、信息图、片头片尾、整段绘制成片等）；可**直出**、**渲后导入编辑**、**未渲拼合预览**，或与剪辑轨**最终一并渲染** | **Phase 1 壳层已落地；像素管线与 Gate 未做** |

### video-use 转正（原「附属 overlay」→ 正式策略入口）

和零口径（2026-10-23）：上游 video-use 里原先当作**剪辑附属 overlay** 的 HyperFrames / Remotion / Manim / PIL 绘制能力，现**转正**为：

1. **Agent 可主动调用的 Skill**（内置包 `video-use`，见 [`skills/video-use/`](../skills/video-use/)）
2. **生产视频策略之一**（归思路二；也可在混用场景为思路一主轨提供绘制层）

| 项 | 约定 |
|---|---|
| 命名 | Skill id 仍为 `video-use`（VAC adapter `0.1.0-vac.5`，文案已转正；绘制 tool 未接线）；绘制面在包内以「绘制/构图策略」一等能力描述，不再写成「仅 overlay 附属」 |
| 触发 | 用户/脚本工作台选 lightweight 或后续绘制向 flow/自定义组合，且目标含程序化画面、无源片成片、或明确要求 Remotion/HyperFrames/动画构图时，Agent **主动**读本包并走绘制管线，而非只做口播删废 |
| 输入 | 工程可见资源（可为空或仅参考）、goal/脚本意图、构图规格（分辨率/帧率/时长）、可选品牌模板；禁止扫盘、任意 shell、私装依赖 |
| 输出 | 受控渲染产物（MP4/WebM）→ 登记为工程资源；可选：直出交付变体，或在发起序列帧零建独立 Agent 视频轨组（对齐现有「完整 Skill 成片入轨」）回灌时间线。Phase 1 尚未产生这类产物 |
| 挂接 | 脚本工作台选 Skill/流程 → Harness `skill_runs.*` + 受控 tool 契约；绘制步骤须进独立预算项；定稿/人工闸门与思路一相同，Agent 不得自批自过。绘制 tool 仍未接线 |

**分层（并列，不互相替代）：**

| 层 | 角色 |
|---|---|
| **策略入口 / 可调用 Skill** | `video-use`：Agent 主动入口；同时覆盖思路一轻量剪辑面与思路二绘制面（绘制面 tool/沙箱仍属 DRAW01） |
| **专用绘制 Skill** | `vac-draw-hyperframes` / `vac-draw-remotion` / `vac-draw-pipeline`：引擎专精说明包，可被 video-use 委托或由用户在自定义组合中点选；`instructions_only`、tools 为空、无 shell |
| **组件 / 运行时** | HyperFrames、Remotion、模板库、沙箱与渲染 Worker：服务上述 Skill，不是产品叙事上的「第三条思路」。Phase 1 未安装、未调用 |

### 引擎分工（事实口径，不发明能力）

- **[HyperFrames](https://github.com/heygen-com/hyperframes)**：HTML/CSS + 可寻址动画（如 GSAP）构图；无强制 React/构建步骤；CLI `lint` / `validate` / `render`；适合 Agent 写 HTML、产品 UI 动效、kinetic type、透明 WebM、确定性逐帧捕获。Node.js 22+。
- **[Remotion](https://www.remotion.dev/)**：React/CSS 组件树构图与 `remotion render`；适合已有 React 品牌组件、需要组件状态与复用原语、或用户明确要求 Remotion 的场景。
- 选用规则：按构图模型选引擎，不因「偏网页」就默认 Remotion；可与素材轨混用（绘制层 + 剪辑层），混用不改变「两条思路并列」。Phase 1 不执行上述 CLI。

### 绘制专用管线 · 独立分页 UI

<a id="draw-page"></a>

和零口径（2026-10-23）：专用绘制管线用**一个独立顶栏分页**承载，并把 skill 原本带有的**网页版预览**设计结构融合进该页——不是塞进编辑页右侧折叠条，也不是另起浏览器外链窗口作为主入口。

#### 与「少开顶栏分页」的关系（显式例外）

产品偏好仍是：**优先把能力做成现有主界面里的模块**，少开顶栏分页。思路二绘制管线是**明确例外**：构图预览、时间轴、源码/图层、Inspector、Lint/渲染队列与剪辑时间线心智不同，硬塞进「编辑」会挤掉 Premiere 式双监视器工作流。因此新增一个顶栏工作区（id `draw`，标签「绘制」），与现有 `resources` / `editing` / `export` / `tts` / `settings` 并列；**不得**借此再拆一串绘制子顶栏。页内用 Ant Design 分区/侧栏 Tab，不再增加顶栏页。键盘 `6` 打开该页；`1`～`5` 仍是原工作区。

视觉：VAC 灰阶统一暗底、Ant Design 5 实心控件；**禁止** liquid glass / 渐变发光（与现行 webui 规范一致）。

#### 上游网页预览结构（融合来源）

上游 video-use 绘制面依赖的浏览器预览，以 **[HyperFrames Studio](https://hyperframes.heygen.com/studio)**（`npx hyperframes preview`）为主结构蓝本；引擎为 Remotion 时，同一 VAC 页内切换为 **Remotion Studio** 等价分区（左构图列表、中 Player、下 Timeline、右 Inspector/Renders），不新开第二个顶栏页。Phase 1 只融合分区，不运行该命令，也不把命令交给前端。

#### 与脚本工作台 / 编辑时间线的关系

和零口径（2026-10-23）补充：**绘制 ↔ 编辑可双向衔接**，未渲构图也可先拼合预览，最终可与剪辑轨一并渲染。

| 方向 | 约定 |
|---|---|
| 进入 | 脚本工作台、Skill 运行（`video-use` 或 `vac-draw-*`）、编辑时间线可深链打开「绘制」页，查询参数携带当前 `project`、`run`、`slot`、`engine`、`focus`。深链不切换到另一个工程 |
| 页内完成 | 在本页预览、lint/check、渲染；成功产物登记为工程资源；可**直出**到导出/交付。Phase 1 这些动作显示「方案接线中」 |
| 渲后导入编辑 | **画面生产（渲染）完成后，可直接导入「编辑」工作区**（对齐现有完整 Skill 成片入轨：帧零独立 Agent 轨组或显式导入），再混剪/对照。契约名 `import_into_editing` |
| 未渲拼合预览 | **未渲染导出的构图**也可与其它绘制槽位、编辑轨**拼合在一起预览**效果（合成预览，不等于已定稿像素轨）。契约名 `composite_preview`，不要求先有 MP4 |
| 最终一并渲染 | **多个绘制槽位 + 编辑轨**可合并到最后**一起渲染**成片；不必每个绘制槽先单独导出再二次编码。契约名 `merge_render` |
| 边界 | 「绘制」页时间轴只编辑**构图源**时间；工程多轨剪辑仍只在「编辑」页。已渲 MP4 不当作可无损拆开的构图源；要改字体/关键帧须回构图源再渲 |

### 与思路一的选用边界

| 场景 | 优先思路 |
|---|---|
| 有完整录屏/口播素材，要删废、对齐解说、交 Premiere | 思路一（剪辑；video-use 剪辑面） |
| 无源片或源片仅作参考；要做片头、UI 演示、数据动画、纯运动图形成片 | 思路二（绘制；video-use 绘制面或专用 draw Skill） |
| 口播粗剪 + 需要程序化标题/图表层 | 混用：思路一出主轨，思路二出绘制层再叠加或并轨 |

### 风险（立项前必须写清）

- **依赖与运行时**：Node 大版本、Chromium/Puppeteer、本机 GPU/CPU 渲染成本；桌面发行是否捆绑或首次引导安装。
- **渲染成本与预算**：长构图与高帧率会显著占步数与墙钟时间；需单独预算项，不能 silently 占满剪辑预算。
- **人类可编辑性**：渲染后的像素轨可剪时长/位置，但构图参数（字体、关键帧）在 VAC 时间线内默认不可深度回编；要保留构图源文件与版本，否则细调只能重渲。
- **Gate**：落地后另开验收项（引擎版本、样例构图、导入时间线、直出哈希）；当前**不得**记入冲刺完成或 REL 范围。
