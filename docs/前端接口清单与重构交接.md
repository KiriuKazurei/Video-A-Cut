## 页面与直接组件调用

App 维护资产/流程选择与 runtime/update 状态。EditingWorkspace 通过 useWorkflowData 共享工作流数据，PreparationPanel 负责固定预设与预检，WorkflowPanel 在内容页改稿、在审查页确认/批准。AutoRunStart/AutoRunProgress 消费 auto 读模型及授权/decision/revoke；ExportWorkspace 组合预览、交付、样式与人工验收。Monitor/Timeline 通过 PreviewScope 回调和 workflow context 绑定选中的 asset/run/revision，媒体键通过受控 URL 构造，不把 artifacts 路径直接当地址。

## 查询、事件与持久化

TanStack Query 的资产、workflows/workflow/review、auto、预设、能力、preview、variant、TTS 等缓存由对应写操作失效；SSE 连接/重连重新取 REST 快照。选择和媒体归属必须核对 asset/run/revision。页面保持挂载不能放松隐藏页、焦点或模态框的快捷键守卫。C/A 对应当前审查项；N 导航不会自动批准其他项。

新手引导与侧栏宽度使用 localStorage；自动模式启动选择不再记忆。预设草稿与保存的不可变版本区分，异步载入失败不能无限重试，预设选择与实际请求版本必须一致。新建预设通过已有能力接口发现本机声音，不覆盖用户明确填写或已保存的声音。

## TTS 与固定模板

tts/capabilities 只提供能力/声音/凭证是否就绪的投影，不返回密钥。模板保存为不可变版本，正式工作流绑定版本和配置摘要；独立 preview-jobs 支持状态、取消和音频读取。SAPI 无声音或模板外部凭证不可用要明确失败；本机测试桩不能当真实语音质量证明。
