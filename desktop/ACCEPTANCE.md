## 同机性能小样本

CPU：Ryzen 7 5800H；GPU：RTX 3070 Laptop。
Release 桌面与可见 Edge 浏览器使用相同 Go/Worker、同一生成媒体、GPU 开启、
1440×900 CSS 内容尺寸；同为 Edge 148 引擎。
720p 预设不放大原素材，实际预览仍为 320×180、4 秒。
播放采样 6 秒；跳转 5 次；导航绘制 15 次。

| 指标 | Tauri 桌面 | 浏览器基线 |
|---|---:|---:|
| 导航绘制延迟中位数 | 125.6 ms | 117.8 ms |
| 播放跳转延迟中位数 | 9.8 ms | 8.2 ms |
| 播放帧 / 掉帧 | 181 / 0 | 181 / 0 |
| 所属进程工作集之和 | 1198.3 MiB | 1175.0 MiB |
| 所属进程私有字节之和 | 1054.6 MiB | 1091.4 MiB |

所属进程包含宿主、浏览器/WebView、Go、Worker 及采样时后代。
工作集累加可能重复计算共享页，因此同时记录私有字节。
原始数据位于 `.run-data/tauri-live/performance.json`。
本轮没有显示明确的响应或播放性能优势，私有字节略低。
短低分辨率素材不能代表长录像、1080p/4K、持续多任务或稳定统计收益；需要后续专项对照。
