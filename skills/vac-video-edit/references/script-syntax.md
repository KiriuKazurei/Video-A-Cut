# VAC 脚本语法 v3

目录：上下文 → 指令表 → 时间与绑定 → 可用示例 → 错误处理。

脚本是编辑数据，不是可执行JavaScript、Python或模板；AVS导入导出仍为v2，语法v3不等于AVS v3。权威定义是服务端提供的语法说明与 `project/script_directives.json`。

## 先确定上下文

**普通脚本**：空行分段；正文是创作要求，各段对应生成计划的一段旁白/素材选择。旁白存入segments，不把指令正文直接当已生成旁白。每段可有多个引用、最多一个旧整段字幕、多个命名定时字幕和一个入口转场。生成旁白路线每段最多选择一个视频源，不同视频拆为不同段。输入上限64KiB/100段，但可执行扁平计划仅1–20段。

**代码条**：以稳定clip_id绑定，空行保留，不能拆成新条。自然语言描述用于显式重新生成源码；参数指令直接作用于本条，无需重新调用Agent。完整作者文字保存在 `code.script`，`description` 只是创作描述；编辑参数时保留其他文字/空行及指令，不用只含description的字符串覆盖全文。

## 指令表

参数分隔和冒号优先用半角；字符串使用JSON双引号。可选参数可省略，不能杜撰参数。

| 指令 | 上下文 | 字段与意义 |
|---|---|---|
| `{@识别名}` | 段落/代码条 | 资源或标记引用；使用具体稳定绑定，不是任意路径 |
| `{#卡号}`、`{#卡号/变体}` | 段落/代码条 | 一段或一个代码条选一张镜头卡。绘制运行的工具列表提供 `draw.shot` 时，读取精确配方和源码，再按正文适配或原样实例化 |
| `{"原样字幕"}` | 段落/代码条 | 旧整段/整条字幕；可加 `字号:24px`、`字体:"Microsoft YaHei"`，允许一个末尾逗号 |
| `{字幕, 文本:"开始", 时间:条内1s, 持续:2s}` | 段落/代码条 | 文本必填；可选时间/持续/字号/字体。字号1–512px，字体须已安装；可多条/重叠，持续省略到段尾/条尾 |
| `{黑屏}` | 段落/代码条 | 段/条入口经过黑色淡变，不是永久生成黑屏 |
| `{白屏}` | 段落/代码条 | 段/条入口经过白色淡变 |
| `{交叉溶解}` | 段落/代码条 | 与前一画面溶解；序列中要求相邻片段与真实源余量 |
| `{音量, 增益:-6dB}` | 仅代码条 | 增益必填，-96..24dB；可选起始增益、时间、持续；只控制此条声明的声音 |
| `{移动, x:100px, y:0px, 持续:2s}` | 仅代码条 | x/y必填，-100000..100000px；相对画布中心；可选时间/持续 |
| `{旋转, 角度:30, 持续:2s}` | 仅代码条 | 角度必填，顺时针，-100000..100000；可选时间/持续，无deg后缀 |
| `{缩放, 比例:120%, 持续:1s}` | 仅代码条 | 比例必填，1..800%；可选时间/持续 |
| `{透明度, 从:0%, 到:100%, 持续:500ms}` | 仅代码条 | 到必填，从可选，0..100%；可选时间/持续 |

普通段落不接受音量/移动/旋转/缩放/透明度；这些需求走时间线或代码条原生参数。没有新“旁白”指令，不支持opi、缓动字段、元素选择器、任意表达式、网络/命令执行块。不能用 `{镜头...}`、`{时长...}` 等自造语法表达普通创作要求，把要求写在块外。

## 时间、转义与稳定绑定

- 省略时间表示段/条起点。`时间:条内1s`、`条内500ms`、`条内30f` 明确局部时间；`时间:序列00:00:10:00` 明确序列时码。旧裸时码也按序列时间，不能当条内时间。时长用s/ms/f；带帧时码使用非丢帧规则，不是小数秒。
- 在当前序列有理FPS下转换为条内整数帧；源码自身帧时钟另算。例：30fps下条内1s=30帧，500ms=15帧。对30000/1001等FPS按实际转换/舍入，不用固定30替代。
- 非字幕动画省略持续表示立即变化；有持续使用线性插值。同属性重复时刻/重叠动画、越界时间及未知/重复字段都报错。字幕允许重叠，不能套用动画重叠限制。
- JSON字符串里的逗号、冒号、花括号是文字；双引号/反斜杠/换行用 `\"`、`\\`、`\n`。块外字面花括号用 `\{` 和 `\}`。写进JSON请求时再由JSON序列化转义一层，不手工拼多层字符串。
- `{@名称}`显示文字不等于绑定。先 `references.list`，明确候选的kind/target_id/resource_id/sequence_id/clip_id；AVS v2每次出现以UTF-16 start/end偏移绑定，不能用UTF-8字节数或Python字符数直接代替，emoji尤其要注意。
- 源标记锚定指定片段实例中的源帧；单点是一帧有效锚，不要求出点，也不能生成零时长片段。被删除/修剪掉的引用须重绑，不能自动取同名项。时间线标记和源标记的跟随规则不同。

## 普通脚本示例

假设当前工程已有明确选中的“操作演示.mp4”和“结果演示.mp4”，帧证据支持内容；完成引用绑定后使用：

```vac-paragraph
{@操作演示.mp4}简要介绍操作步骤，旁白依据画面说明，不补写无法确认的规则。{"操作步骤", 字号:36px}{黑屏}

{@结果演示.mp4}展示最终结果，保留源素材声音。{字幕, 文本:"结果，{原样}", 时间:条内1s, 持续:2s, 字号:24px}{交叉溶解}
```

第二段至少3秒才能容纳字幕；源窗口需来自media.list允许范围且经检查，不能从脚本文字猜切点。若帧证据不支持要求，说明冲突。强制字幕不自动成为旁白；关闭自动字幕也不能静默移除显式强制字幕。

扁平段落渲染默认1280×720/30fps、36px描边字幕；交叉溶解会缩短扁平成片总长。多轨序列使用自身画布/有理FPS，溶解保持序列时长；两者不能混算。

## 代码条示例

适用至少4秒的代码条，当前序列30fps；缩放、位置、透明度使用不同属性，可同时出现：

```vac-code
蓝色背景，白色标题“开始”，保留可编辑源码。

{透明度, 时间:条内0f, 从:0%, 到:100%, 持续:500ms}
{移动, 时间:条内0f, x:100px, y:0px, 持续:1s}
{旋转, 时间:条内0f, 角度:30, 持续:1s}
{缩放, 时间:条内1s, 比例:120%, 持续:1s}
{字幕, 文本:"开始，{原样}", 时间:条内1s, 持续:2s, 字号:24px}
{音量, 增益:-6dB}
```

音量只影响源码audio_bindings，不为无声源码生成声音，也不控制其他音乐/旁白轨。以上参数不应再次烘焙到生成源码，否则会重复变换。

## 发现错误时

读取服务端行列诊断，只修改实际错误；保留用户描述及原先有效画面。缺字体不静默替换；未知指令不丢弃；不完整括号不改读为旁白；越界字幕不截短隐藏问题。无效文本可作为草稿保留，不能将“保存草稿成功”报告成参数已生效。
