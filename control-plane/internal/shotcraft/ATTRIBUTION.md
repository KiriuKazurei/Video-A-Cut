# Video Shotcraft

The shot recipes, reference sources and shared components in `upstream/` are from **Vincentwei1021 (Yihao Wei)** and contributors, under Apache License 2.0. VAC uses commit `1266a3ec4831289c4d893d42dd5102723658039a`. The license text is included alongside this notice in distributions. [Upstream source](https://github.com/Vincentwei1021/video-shotcraft/tree/1266a3ec4831289c4d893d42dd5102723658039a)

VAC generated the catalog and adapted the executable templates for the local Remotion worker. Changes include a default component export, bundled helper code, project-owned image bindings, replacement of shared brand graphics, and a local frame-sampling implementation for four camera blur variants. Original source and recipe files retain their upstream text. Demo screenshots, music, sound effects, fonts and rendered previews are omitted from this distribution.
