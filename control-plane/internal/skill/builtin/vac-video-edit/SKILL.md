# VAC 视频编辑

通过 VAC 当前工程的受控工具完成用户的编辑目标，保留可继续编辑的工程结构，并检查真实产物。本 Skill 是客户端操作指导；创建 VAC 任务时，`skill_id` 使用服务端实际提供的执行包，不填 `vac-video-edit`。

## 版本与连接

本 Skill 版本 **0.5.3**，对应编写基线 VAC **0.5.3**；声明兼容范围 **>=0.5.1 <0.6.0**，已核对 **0.5.1** 至 **0.5.3** 的相关源码合同。范围内其他版本须通过工具与语法合同检查，不能仅凭版本号宣称兼容。兼容判断和何时升级见 [版本兼容](references/compatibility.md)。

使用 VAC 桌面连接面板提供的 MCP 地址与安装配置，不猜端口。VAC 0.5.3 初始化会提示用 `skills.get {id:"vac-video-edit"}` 获取本文。按返回的摘要用 `skills.read_resource` 读取参考，无需提前安装宿主 Skill。连接后读取实时工具 schema、`skills.list/get` 和执行包的 `vac/tool-contracts.md`；服务端合同优先于本地速查。若当前会话没有 VAC MCP，说明缺少连接及所需入口，保留编辑方案；不把本 Skill 当作已经连接，也不直接读数据库或另起 FFmpeg 替代 VAC。

## 根据脚本和素材选路

自然语言脚本是创作要求。先读目标、可见素材和时间线，保留显式资源、镜头卡、字幕与时间约束，再为未指定的段落决定素材与剪法。外部 Agent 用 `execution_mode:external_mcp`，自行提交明确的 `flow`、`skill_id` 和 `strategy`。省略字段会沿用工程默认，`custom` 也只是流程标识。

| 决定成片的依据 | 路线 |
|---|---|
| 说了什么、在哪个词或停顿处切 | 轻量口播，`lightweight / video-use / edit`。先核对词级转录依赖与授权。 |
| 画面何时发生关键变化 | 画面摘要，`visual_heavy / vac-visual-summary / edit`。定向抽帧验证，转录可按需使用。 |
| 需要创造标题、图表、UI 动效等新画面 | 绘制，`custom / vac-draw-pipeline / draw`。允许无源视频，按镜头选择源码引擎或镜头卡。 |
| 真实素材和生成画面共同叙事 | 用主素材对应的剪辑包取得证据，按段加入可编辑代码条，在同一序列完成。 |
| 只调整现有时间线或选中的代码条 | 先读取目标实例，直接编辑；局部重新生成源码才捕获 `code_targets`。 |

创建前读 [选路与交付](references/workflows.md) 和 [工具表](references/tools.md)。涉及源码读 [绘制与代码条](references/drawing.md)，写脚本读 [语法](references/script-syntax.md)。

## 每次任务的必要步骤

1. `projects.list` 确认当前工程；读取所需脚本资源、序列、素材与稳定引用。用户交接的脚本以 `resources.read` 返回的已保存正文与修订为准。重名需明确候选，失效引用需重新绑定。
2. 有交接 `run_id` 时先读冻结范围与允许工具，匹配任务再领取；否则先选路，再按实时执行包、媒体指纹与目标序列创建任务。依赖缺失时按选路规则说明取舍，遵守任务预算与授权。
3. 先检查素材帧/词级时间，再决定切点。工具结果必须支持旁白、镜头与字幕的判断；不要把“介绍机制”这类创作要求原样读成旁白。
4. 写入使用返回的版本与稳定ID。每个新动作使用新幂等键；超时且结果未知时，先以原键和相同请求重放，不重复生成或插入。CAS冲突后重新读取、核对用户修改，再构造新请求。
5. 按路线完成实际渲染与检查。普通成片需 inspect → 逐帧读取 → review → finish；结构化时间线使用当前序列修订/内容摘要 finish；局部代码任务可在目标写入成功后 finish。不能混用这三种完成条件。
6. 返回产物名称/ID、检查结论、编辑范围和剩余问题。区分技术质量、Agent画面检查和人工观感；有警告按实际说明，不杜撰人工通过。

## 保持编辑正确

- 只使用当前工程导入资源及任务冻结范围。素材ID、资源ID、片段实例ID、帧产物ID用途不同，不按名称或数组下标互换。
- 源素材计划的 `start/end` 是源秒；序列位置/时长是有理FPS下的整数帧；源码动画使用源码FPS；`source_in/out` 是 `{value,scale}`。先确定时间基准再换算。
- 尊重用户锁、链接音轨、选区与未选内容。保留原剪辑，避免把整体成片替代局部编辑。使用原生参数时不要再把同一变换烘焙进源码。
- 不发明工具、指令、字体、视觉证据或声音产物。工具缺失或 `not_implemented` 时说明实际限制；不要自行下载依赖、读取密钥、联网替换素材或调用付费模型。
- 用户已授权的编辑、生成与导出沿现有流程执行，不人为插入逐步审批；云调用、下载或范围扩展仍按现有授权和服务端策略处理。
- 状态恢复用本任务 `get`、`run.steps`、幂等重放与 `update`；不读人工历史/检查点，不调用人工 undo/redo。取消为终态，不重建任务绕过取消或预算。
