## 2026-10-19 Skill 驱动的双流程

当前改造已在 `agent/vu-skill` 写入项目、Skill/Harness、双 Agent 入口和媒体交付工具。设计来源见 [Skill 双流程架构设计](docs/Skill双流程架构设计.md)，实际接口与验证以顶部链接为准。

- **流程 A：轻量直出**。口播、教程、访谈：项目素材 → 已确认可见集 → video-use → 转录与编排 → 定稿/授权门 → FFmpeg MP4；Premiere 可选。
- **流程 B：画面主导**。游戏/复杂画面：项目素材 → 已确认可见集 → 变化抽帧（连续剧变默认三抽一）→ 多模态内容大意 → 按用户脚本编排 → 定稿/授权门 → FFmpeg 或 Premiere；不强制 ASR。
- **两种 Agent 入口**。外部 Agent 经 MCP 获取 Skill、项目上下文并调用受控工具；内置 Agent 使用配置的 API Key/Provider 执行同一 Skill。流程类型与 Agent 入口独立选择。

Go 管理状态、权限、预算和交付；Agent 解释 Skill。前端已提供 Skill 管理、项目/运行/人工门的类型与 SDK；新页面布局由后续前端工作接入。TTS 复用既有服务。下文 10-18 的验证只覆盖其注明版本。


游戏录屏的预处理、自动剪辑和人工精修交接工具。Go 管理业务事实，Python/Node 执行任务，React 提供工作区，Tauri 提供 Windows 桌面集成。

## 10-18 产品基线与当时验收范围（历史）

受控录屏导入和选段、预设与外发许可、场景/解说审查、TTS 模板、字幕/混音、XML/OTIO/ZIP、MP4 预览和 ASS 派生已实现。默认分步生成；自动模式须明确授权，支持有限重剪、用户决定、放弃和撤销。

资源页区分入库与 Agent 可见，可见集确认后进入脚本。脚本工作台支持人写或先看可见素材再生成、花括号语法与高亮、视频绑定、强制字幕、黑白淡变/溶解、修订/否决/人工定稿和画面交付。脚本或可见集变化会使交付失效并暂停受影响自动流程；恢复必须确认相应范围或精确稿件版本。

用户已要求先不测试、继续完成 F2 及后续缺口。本轮新增段落保留、按段 TTS/字幕开关、TTS 专页定位和修订回写、配音合成接线、站内同版预览与交付清单；这些改动尚未提交或验证。旧自动 worker 完整消费脚本仍待续作；真实模型质量、Premiere 实机导入和新桌面包仍待验。之前的最简检查只覆盖 d67e71d，不能作为当前改动通过证据。详见 [续作清单](docs/F2-F4续作清单-2026-10-18.md)。
