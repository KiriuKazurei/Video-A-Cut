# Video Auto Cut

Agent视频工程工作站：保存创作脚本，让内部或外部Agent读取素材、编排、配音、剪辑和导出；用户可直接在编辑页检查与修改成片。Windows Tauri桌面提供完整功能，浏览器用于开发预览。
